# LockerBuddy for Gumroad

This package is designed to be a one-file download. Buyers can download the product and open `lockerbuddy-standalone.html` in any modern browser without extracting folders or installing anything.

What they get:
- A single HTML file
- No backend or login required
- Local-only data storage on the device
- Backup and restore support
- Works as a simple local web app

Recommended buyer instructions:
1. Download the single HTML file from Gumroad.
2. Open it directly in a browser.
3. If you want the best install experience, you can also run:
   `python3 -m http.server 8000`
   and open `http://localhost:8000/lockerbuddy-standalone.html`

This keeps the purchase friction low and makes the app feel instant and ready to use.
