LockerBuddy for Gumroad

This package is designed to be a one-file download. Buyers can download the product and open lockerbuddy-standalone.html in any modern browser without extracting folders or installing anything.

What they get:

A single HTML fileNo backend or login requiredLocal-only data storage on the deviceBackup and restore supportWorks as a simple local web app

Recommended buyer instructions:

Download the single HTML file from Gumroad.Open it directly in a browser.If you want the best install experience, you can also run: python3 -m http.server 8000 and open http://localhost:8000/lockerbuddy-standalone.html

This keeps the purchase friction low and makes the app feel instant and ready to use.
